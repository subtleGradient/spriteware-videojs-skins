# Artwork provenance

LIQUID ORBIT is an original Video.js theme created for Thomas with AI assistance, licensed under Apache-2.0. The full canonical artwork was regenerated with OpenAI's built-in image generation tool from the owner's original A / Electric Aqua / Chrome Liquid Spaceship concept board.

Production prompt preserved the asymmetric chrome fins, aqua glass, central alpha aperture, horizontal timeline, dominant large Play jewel plus separate Pause/Stop/Previous/Next, left Chapters/Captions and right volume well. A separate precision edit removed baked movable thumbs from the track backgrounds.

Normal, hover, pressed, focus and disabled are real generated image states. Control-state edits changed only intended faces; exports deliberately discard all generated differences outside the registered control masks. This avoids drift in the surrounding shell. Button face alpha is normalized to opaque inside those masks, preventing double alpha compositing at rest while keeping real aperture/exterior alpha.

Moving jewel states were generated from the original exact thumb positions, then cropped and circularly masked at their original sizes: seek60px, volume50px. No CSS gradient/filter fabricates a state. `scripts/export.py` records the precise crop/mask process. Hover, pressed, focus and disabled are visibly different artwork, not palette-only engine effects.

The static proof compositions show the owner's AQUADECK motion-study poster solely as demo content. The shared engine and Video.js remain separately maintained; this theme does not duplicate them.
